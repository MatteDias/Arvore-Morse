# Arvore-Morse

## INTEGRANTES

Matteo Dias
Ryan Dalbelo

## Descrição

Este projeto implementa uma árvore binária em Java para
representar o código Morse das letras do alfabeto e dos
números de 0 a 9.

Cada caminho da raiz até um nó representa um código Morse.
O ponto (.) indica o filho esquerdo e o traço (-) indica
o filho direito.

## Funcionalidades

- Inserção das letras A até Z.
- Inserção dos números de 0 até 9.
- Busca do código Morse de um caractere.
- Codificação de mensagens de texto.
- Decodificação de mensagens Morse.
- Exibição hierárquica dos códigos da árvore.
- Menu interativo no terminal.

## Estrutura do projeto

- Nodo.java: representa os nós da árvore.
- ArvoreBinariaMorse.java: implementa a árvore e suas operações.
- Main.java: executa o programa e recebe as entradas do usuário.

## Como executar

1. Abra o projeto em uma IDE Java.
2. Certifique-se de que os três arquivos estão no mesmo pacote.
3. Execute a classe Main.java.
4. Escolha uma opção no menu apresentado.

## Organização da árvore

A árvore começa com uma raiz vazia.

- Ponto (.): segue para a esquerda.
- Traço (-): segue para a direita.
- Cada nó armazena o caractere correspondente ao caminho.
